# Abstract

This survey reviews 572 papers on heterogeneous multi-model agents published between 2023 and 2026. It groups systems by the specialized models an LLM coordinates, then compares how those components exchange information, handle feedback and uncertainty, and work across application domains. The linked project provides a browsable paper collection and supporting data.
